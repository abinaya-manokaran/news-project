# 📰 Insight Stream: Navigate the News Landscape

## 🚀 Project Overview
Insight Stream is a modern web-based news application designed to deliver real-time, categorized news updates in a clean and user-friendly interface.  
It helps users stay informed while reducing misinformation by providing structured and relevant news content.

This project was built as part of a Data & AI learning initiative.

---

## 🎯 Problem Statement
In today’s digital world, news spreads quickly through social media and online platforms. However, users often face:
- Fake news and misinformation
- Information overload
- Difficulty in finding relevant news

Insight Stream solves this by organizing news into clear categories and fetching real-time updates.

---

## 💡 Features

- 🕒 Real-time news updates using NewsAPI
- 📂 Categorized news (Technology, Business, Sports, Health, Entertainment)
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Clean and minimal UI using Bootstrap
- ⚡ Fast and dynamic content rendering using React
- 🔐 Secure API access via HTTPS

## ⚙️ How It Works

1. User selects a news category from the navbar  
2. The app fetches latest articles from NewsAPI  
3. NewsBoard dynamically updates based on selection  
4. NewsItem displays each article with title, image, and link  
5. User can read full news by clicking "Read More"
